# ADR-0033 — `/api` prefix 를 걷어내고, 문서 노출은 제외 목록으로 가른다

**상태**: Accepted
**대체**: [ADR-0029](0029-drop-api-path-prefix.md) 를 대체한다. 0029 는 `Superseded`.

## 맥락

ADR-0029 는 `/api` prefix 제거를 결정했지만 **`Proposed` 로 멈춰 있었다.** 프론트 합의가
필요한 열린 질문 3개(하드코딩 여부 · iOS 배포 주기 · 브릿지 제거 기한)가 닫히지 않았기 때문이다.

**2026-09-04 그 3개가 모두 문제없음으로 확인됐다.** 따라서 구현에 착수한다.
0029 의 결정 자체(`api.` 서브도메인 위에 `/api` path 를 다시 얹지 않는다)는 그대로 유효하고,
이 문서는 **구현 결과와 그 과정에서 뒤집힌 항목**을 기록한다.

## 결정

### 1. 경로에서 `/api` 를 제거한다

클래스 레벨 `@RequestMapping` 4개(`Auth`·`UserProfile`·`Comment`·`Vote`)를 없애고
메서드에 전체 경로를 둔다. 경로를 알려면 클래스와 메서드를 머릿속에서 합성해야 하던 것을
**핸들러 한 줄로 읽게** 만든다. `ArchitectureTest` 의 클래스 레벨 매핑 금지 규칙을 켠다
(0029 가 `@Disabled` 로 미리 깔아둔 안전망 — 한 줄만 지웠다).

### 2. 과도기 브릿지를 두지 않는다 (0029 에서 뒤집힘)

0029 는 "리버스 프록시가 과도기를 흡수한다"를 제목에 넣고 Caddy rewrite 를 후속 과제로 뒀다.
**열린 질문 1·2 가 문제없음으로 닫히면서 브릿지의 존재 이유가 사라졌다.** 0029 스스로
"후자면 브릿지를 아예 생략할 수 있다"고 적어둔 경로다. 구 경로 `/api/...` 는 살리지 않는다.

### 3. springdoc 은 `paths-to-match` 대신 `paths-to-exclude` 를 쓴다

prefix 가 사라져 **모든 API 를 아우르는 공통 접두어가 없어졌다.** 두 선택지를 놓고 골랐다.

| 방식 | 새 API 경로가 생기면 | 공개하면 안 되는 경로가 생기면 |
|---|---|---|
| `paths-to-match` (세그먼트 나열) | **문서에서만 조용히 빠진다** | 안전 |
| `paths-to-exclude` (제외 나열) | 자동으로 실린다 | **자동으로 공개된다** |

**exclude 를 택했다.** 실제로 match 방식으로 세그먼트를 나열해 봤을 때 `/images` 를 빠뜨릴
뻔했다 — `@PostMapping(path = "/images", consumes = ...)` 형태라 접두어 grep 에 걸리지 않았다.
API 는 계속 늘어나므로 이 누락은 반복되는 반면, 비공개 경로 신설은 드물고 그때는 의식적으로
판단하게 된다.

대가는 명시한다: **내부용·관리자용 경로를 새로 만들면 반드시 exclude 에 더해야 한다.**
설정 주석에 이 조건을 적었다.

## 결과

**측정 (2026-09-04, 로컬 기동 후 `/v3/api-docs` 조회)**

- 문서화된 경로 **21개** — 전 엔드포인트가 실렸다
- `/actuator` · `/scalar` · `/llms.txt` · `/llms.md` · `/error` **0개** — 제외 동작 확인
- 게스트 허용 경로(`/rankings`·`/rankings/top`·`/posts`) 200
- 인증 필요 경로(`/users/me/grade`·`/users/me/badges`·`/users/me/points`) 401
- 테스트 **506개 전량 통과** (클래스 레벨 매핑 금지 규칙 활성 상태)

**트레이드오프**

- 구 경로로 오는 요청은 **깨진다.** 브릿지가 없으므로 프론트 배포와 함께 나가야 한다.
- `SecurityConfig` 매처 9개를 경로 변경과 **같은 커밋**에 넣었다. 나뉘면 인증이 뚫리거나
  정상 요청이 막히는 창이 생긴다.
- 문서 노출이 이제 **fail-open** 이다. 이 성질을 아는 채로 택했다(위 표).
