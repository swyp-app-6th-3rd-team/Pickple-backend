# PRD (Product Requirements Document)

이 사이클에서 **무엇을 왜 만드는가**를 적는다. 사이클이 끝나면 동결한다.
뒤집힌 결정이 있으면 문서를 지우지 말고 뒤집힌 사실과 계기를 남긴다.

**완료 판정은 측정 가능한 것만 적는다.** "잘 동작한다" ✗ → "Q 클래스 파일이 생성된다" ✓.
빌드 green·테스트 통과는 대리지표이므로 그 자체를 완료 판정으로 쓰지 않는다.
